# The validatable plate formats are a startup knob, not a code fork

Argentine traffic is mixed-era: the legacy 3-letter/3-digit format ran 1995 → April 2016 and was replaced only for *new* registrations, so a large share of vehicles in normal traffic still wear `ABC 123`. The operator wants the option to choose, per site, whether legacy plates are recognized. The obvious idea — a separate branch/tag/model per era — is unnecessary: the detector is country- and format-agnostic (ADR-0004), and the OCR alphabet is length-agnostic, so **all format knowledge lives in the validation table**.

Decision: one `.env` setting, `PLATE_FORMATS` with two values — `MERCOSUR_ONLY` (default in `.env.example`, today's behaviour) and `MERCOSUR_PLUS_LEGACY` (what the operator's own `.env` runs). `MERCOSUR_PLUS_LEGACY` adds exactly one format — the legacy car `ABC 123`, status `VALIDATED_LEGACY`, vehicle class empty. Detection, tracking, event identity and the CSV shape are untouched; consensus "prefer-validated" voting treats legacy readings as validated when the knob is on.

Consequences and caveats: pattern collisions are real and current — Paraguay (`ABC 123`, still coexisting since 2019) and Peru (`ABC-123` still valid since 2010) cross into legacy-validated rows; accepted, the separate status keeps them filterable. Separator-letter re-issues (`ABC D123`, duplicate/triplicate registrations) normalize to 4-letters-3-digits and stay `UNVALIDATED` — no lenient regex. OCR quality on the 6-char layout is model-dependent: the 7-slot `arg_cnn_ocr` fallback was trained on Mercosur lengths, so `.env.example` documents that legacy mode wants the default `cct_s_v2_global`; not enforced (the bad combination degrades toward `UNVALIDATED` rows). The empirical check ran and passed: a 38,962-crop sweep of the Test-rig stream through the default `cct_s_v2_global` produced 683 legacy-shape readings from about nine distinct plates, each read identically across consecutive sightings (e.g. `OWY729` 21 times, `JLG827` 11). The dashboard gives `VALIDATED_LEGACY*` its own amber style.

Rejected: separate model/branch per era (the original ask — no payoff since detection/OCR are format-agnostic); always-on legacy validation (silently changes shipped semantics and pays the collision noise everywhere); assigning legacy plates a vehicle class (the characters prove none — car and cargo variants shared them).
